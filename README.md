# Meu Portfólio Angular
Projeto desenvolvido para praticar Angular e criar um portfólio pessoal.

## Tecnologias
- Angular
- HTML
- CSS

## Ambiente
Node.js: v20.x.x
npm: v10.x.x
Angular CLI: v19.x.x

## Como executar
npm install
ng serve
